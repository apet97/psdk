# pumble-sdk Docs Site Plan

Do not build a docs site until Markdown docs and package exports are stable.

Minimum launch content:

- Install and quickstart.
- Raw SDK reference.
- Facade workflows.
- CLI commands.
- Curated MCP safety model.
- Webhook verification.
- Stability matrix.
- Error model.
- Release evidence.
- Support matrix.

Recommended implementation: generate static docs from existing Markdown first. Avoid duplicating source-of-truth content.
