# API Reference

## Raw SDK

Import `PumbleSDK` from `pumble-sdk`. Resource groups are `channels`,
`messages`, `scheduledMessages`, and `users`.

## Facade

Import `createPumbleClient` from `pumble-sdk/extensions/index.js` for
human-target resolution, receipts, facade failure values, and resolver cache
controls.

## MCP

Use `pumble-mcp start --profile curated` for agent-facing tools. Writes use
preview and confirmation.

## CLI

Use `pumble --help` for command syntax.
